# Personal Expense Tracker

## About the Project
Personal Expense Tracker is a simple console-based
application developed using C programming.

It helps users manage their daily expenses.

## Features
- Add new expenses
- View all expenses
- Calculate total expenses
- Search expenses by category
- Simple menu-driven interface

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- Loops
- String Handling

## How to Run

1. Download or clone this repository.
2. Open the main.c file in Code::Blocks or VS Code.
3. Compile and run the program.
